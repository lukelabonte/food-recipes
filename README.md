# Our Recipes

A family recipe collection. Each recipe is a styled HTML page hosted via GitHub Pages, formatted for easy import into [MacroFactor](https://macrofactorapp.com/).

**Browse recipes:** [lukelabonte.github.io/food-recipes](https://lukelabonte.github.io/food-recipes/)

## How It Works

1. Send a recipe to Claude in any format (photo, handwriting, URL, YouTube video, text, PDF)
2. Claude extracts the recipe, builds a styled HTML page, and pushes it here
3. Copy the GitHub Pages URL into MacroFactor's Import feature
4. Enter the estimated cooked weight that Claude provides
5. Done

## What Each Recipe Includes

- Ingredients with gram equivalents for every measurement
- Proofread, numbered steps optimized for reading while cooking
- Estimated uncooked and cooked weights (conservative, for calorie tracking)
- Nutrition info labeled as "from source" or "estimated"
- Tips when applicable
- Print-friendly layout

## Search

The index page includes a fuzzy search bar that filters recipes by name, description, ingredients, cook time, and more. Typo-tolerant (e.g., "chiken" finds "Chicken Noodle Soup").

- **Powered by:** [Fuse.js](https://www.fusejs.io/) for client-side fuzzy matching
- **Search index:** `recipes.json` is auto-generated by a GitHub Action on every push — never edit it manually
- **No build step:** Everything runs client-side on GitHub Pages
