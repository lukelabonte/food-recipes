# Food Recipes

A collection of recipes formatted for easy import into [MacroFactor](https://macrofactorapp.com/). Each recipe is a standalone HTML page hosted via GitHub Pages.

**Browse recipes:** [lukelabonte.github.io/food-recipes](https://lukelabonte.github.io/food-recipes/)

## Categories

- `appetizers/`
- `beverages/`
- `breakfast/`
- `desserts/`
- `main-dishes/`
- `salads/`
- `sauces-and-dressings/`
- `side-dishes/`
- `snacks/`
- `soups-and-stews/`

## How It Works

1. Send a recipe to Claude (photo, URL, video, handwritten, text — any format)
2. Claude extracts the recipe, builds an HTML page, and pushes it here
3. Copy the GitHub Pages URL into MacroFactor's Import feature
4. MacroFactor parses the ingredients and steps automatically

Each recipe includes estimated gram weights for all ingredients, cooked weight estimates, and nutrition info (labeled as from-source or estimated).
